#  React native (Todo_app)

I developed a cross-platform ToDo List application using React Native and Expo. The app supports CRUD operations, allowing users to create, read, update, and delete tasks. I also integrated AsyncStorage to store tasks locally on the device, ensuring data persistence even after the app is closed.


#React Native is a open-source framework for building mobile applications using javascript and React.
It allows me to build mobile applications for both android and ios using a single codebase.
